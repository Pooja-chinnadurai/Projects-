Smart Medicine Dispenser (IoT + Blynk)

An IoT-powered automated system that reminds, dispenses, and tracks medicine timings using mobile connectivity.

🔧 Project Highlights

  • Automated dispensing using microcontroller-based control
  • Integrated with Blynk IoT App for scheduling & notifications
  • Real-time alerts for medicine time and missed doses
  • Sensor-based dose confirmation
  • User alerts through buzzer and phone notifications

📱 How the System Works

The user schedules medicine timings through the Blynk app. When the time arrives:

  1. Microcontroller triggers the motor
  2. Correct dose is dispensed
  3. Sensors verify the action
  4. Instant notification is sent to the user

🛠️ Technologies Used

  • Arduino / NodeMCU
  • Blynk IoT Platform
  • IR Sensor
  • Servo / DC Motor
  • C / Embedded Programming
  • Wi-Fi Connectivity
